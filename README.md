# Virginia data-center backup generators: public records and analysis

A static site for exploring Virginia Department of Environmental Quality public records on data-center backup diesel generators (NextRequest requests 26-5161 and 26-5337, published at vadeq.nextrequest.com), with generator run logs extracted from the released spreadsheets and analyses of grid outages, emissions, dispersion, health impacts, air quality, demographics, taxes, electricity prices, the PJM capacity market and large-load interconnection.

Every page lists its sources. Documents link to the DEQ public portal. Estimates are screening-level; see the Methods page for assumptions, the methods review and corrections.

Open `index.html`, or visit the GitHub Pages site.
